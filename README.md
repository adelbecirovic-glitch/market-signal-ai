# Market Signal AI

Ein einfacher MVP-Scanner für:

- S&P 500
- Nasdaq 100
- Dow Jones
- DAX
- Gold
- Silber
- Kupfer
- Bitcoin
- Ethereum
- Solana

## Start

Python 3.10+ installieren.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Danach öffnet Streamlit die App im Browser.

## Enthalten

- EMA 20 / 50 / 200
- RSI
- MACD
- ATR
- Volumenfilter
- 20-Perioden-Breakouts
- Long/Short-Score 0-100
- Stop- und Target-Vorschläge
- Tages- und 1-Stunden-Ansicht

## Noch nicht enthalten

- News-/LLM-Sentiment
- Makrodaten
- Funding Rates / Open Interest
- Telegram / Discord
- Backtesting
- Paper Trading
- Broker-Ausführung

Wichtig: Dies ist ein Analyse-Prototyp und keine Anlageberatung.
